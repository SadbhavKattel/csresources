# cheat sheet series (TikTok, 1080x1920)

Six posts, each `1-cover.png` + `2-sheet.png` + `3-sheet.png` in `output/NN-topic/`:
big-o, git, sql, calculus, machine learning, python.

Content lives in `sheets.py`; run `python3 make_sheets.py [slug ...]`.

Accuracy: every Python, SQL (SQLite 3.45) and Git example was executed, and every derivative
and integral rule was checked with sympy before rendering.

Fonts: Nimbus Sans (Helvetica clone), JetBrains Mono (ligatures off), DejaVu Sans for math.
